# mmlaw.ge — MMLAW Law Firm

Static, three-language website (Georgian (default) at `/ka/`, English at `/en/`, Russian at `/ru/`; the bare domain and root paths forward to `/ka/`),
served by GitHub Pages from the repo root. Formerly lfs.ge.

## Edit & rebuild

All text lives in `tools/content.py` (services, FAQs, blog posts, UI strings — in ka / en / ru).
After editing, regenerate the pages:

```bash
python3 tools/build.py        # rebuild all HTML, sitemap.xml, robots.txt, llms.txt
python3 tools/build.py --og   # also re-render social share images (needs Google Chrome)
```

- Styles: `assets/site.css` · Behaviour (mobile menu, form): `assets/site.js`
- Generated HTML carries a `generated by tools/build.py` marker — don't edit it by hand.
- To add a blog post, append to `POSTS` in `tools/content.py` (all three languages) and rebuild.

## SEO / AEO

- `hreflang` alternates + `x-default` on every page, canonical URLs, Open Graph / Twitter cards
- JSON-LD: `LegalService` (firm), `WebSite`, `WebPage`, `BreadcrumbList`, `Service`, `FAQPage`, `BlogPosting`
- `sitemap.xml` with language alternates, `robots.txt` (AI crawlers allowed), `llms.txt`
- Root paths (`/`, `/about/`…) forward to `/ka/…`, which also matches the old lfs.ge `/ka/` URLs
